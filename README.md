# Institutional Evidence Tracker

A small evidence-and-dependency tracker for administrative processes where progress depends on identifying the next decision owner, required evidence, unresolved dependencies and an auditable action history.

## Implemented
- evidence records with provenance
- decision-owner tracking
- dependency states
- requests and responses
- next-action calculation
- chronological audit log
- deterministic tests

## Origin and boundary
The design is informed by experience tracing multi-step administrative/document processes. It is a generic software prototype, not a legal-advice system and not a claim that any particular institution uses it.
